## 1. 品牌定位

**我们是谁**
后端基础设施与 Agent 系统开发团队。不为概念叙事，为工程落地。

**品牌核心**
`Reliable Intelligence` —— 可信赖的智能。强调稳定、可维护、可扩展的 AI 工程化能力，拒绝“为 Agent 而 Agent”的炫技。

**受众优先级**
1. 后端工程师与架构师
2. AI 应用开发者
3. 企业技术决策者

## 2. 视觉识别系统

### 2.1 品牌色

| 角色                   | 色值                               | 使用场景                     |
| ---------------------- | ---------------------------------- | ---------------------------- |
| **深空黑** `#0B0C10`   | 主背景、导航栏、关键标题           | 数字界面深色模式、印刷主色   |
| **技术靛蓝** `#4F46E5` | 主行动色、链接、高亮数据           | CTA 按钮、图表主色、代码高亮 |
| **荧光青** `#06B6D4`   | 辅助强调、状态指示、Agent 活性标识 | 运行状态、流式输出光标、徽章 |
| **中性灰** `#9CA3AF`   | 正文、次要信息、禁用状态           | 正文描述、时间戳、辅助文本   |
| **纯净白** `#F9FAFB`   | 深色背景上的文字、留白             | 反白文字、卡片底色           |

**禁用**：高饱和渐变（紫-粉-蓝炫光）、纯黑 `#000000`（过于生硬）、默认纯蓝 `#0000FF`。

### 2.2 字体

- **英文/数字**：`Inter` 或 `JetBrains Mono`（代码场景）。字重优先 400（Regular）、600（SemiBold）。
- **中文**：`PingFang SC`（苹方）或 `Noto Sans SC`。禁止在标题中使用衬线体（如宋体）。
- **代码展示**：统一 `JetBrains Mono`，字号比正文小 1-2pt，行高 1.6。

## 3. Logo 规范

### 3.1 图形释义

Logo 由两个几何单元构成：**六边形节点**（代表分布式后端）与**内切循环箭头**（代表 Agent 的感知-决策-执行闭环）。整体呈非对称稳定结构，隐喻“受控的智能”。

### 3.2 安全空间

Logo 四周留白不得小于图形高度的 25%。最小使用尺寸：
- 数字：宽度 ≥ 32px
- 印刷：宽度 ≥ 20mm

### 3.3 色彩模式

| 背景          | Logo 版本                    |
| ------------- | ---------------------------- |
| 浅色/白底     | 深空黑主 Logo                |
| 深色/黑底     | 纯净白反白 Logo              |
| 技术靛蓝背景  | 纯净白反白 Logo              |
| 复杂图片/视频 | 带 20% 黑色遮罩的纯净白 Logo |

### 3.4 绝对禁止

- 拉伸、旋转、倾斜、添加阴影/描边；
- 改变品牌色为亮紫、橙红等情绪色；
- 将 Logo 作为句子中的普通图标使用；
- 在低于 25% 透明度时使用。

## 4. 文案语调（Tone & Voice）

### 4.1 总则

冷静、精确、工程师友好。我们相信技术本身的说服力，不依赖形容词堆叠。

### 4.2 用语规范

| 推荐                                  | 禁止                   | 原因                   |
| ------------------------------------- | ---------------------- | ---------------------- |
| “Agent 编排延迟降低 40%”              | “极速 Agent，引领未来” | 用数据替代形容词       |
| “支持 Java / Python 原生 SDK”         | “全链路打通，生态赋能” | 具体技术栈 > 黑话      |
| “该方案在 10k QPS 下保持 P99 < 200ms” | “高并发场景轻松应对”   | 可验证指标             |
| “请参阅文档” / “当前不支持”           | “亲，很抱歉哦”         | 平等、直接，拒绝客服腔 |
| “Beta 版本，已知限制如下：”           | “完美无瑕的革命性突破” | 诚实披露风险           |

### 4.3 英文文案

- 使用美式拼写（`orchestration` 而非 `orchestration`）。
- 首字母大写仅用于句首及专有名词，禁止标题全大写（如 `RELIABLE INTELLIGENCE`）。
- 代码相关名词保持原样：`API`、`SDK`、`LLM`、`RAG`、`ReAct`。

## 6. 应用场景规范

### 6.1 数字界面（官网 / Dashboard）

- 背景：深空黑 `#0B0C10` 为主，纯白 `#FFFFFF` 为文档页背景。
- 卡片：比背景亮 5-8% 的灰（`#151621`），圆角 8px，边框 1px `#27272A`。
- 代码块：深色背景，荧光青用于字符串与关键字高亮，注释使用中性灰。

### 6.2 技术白皮书 / PDF

- 封面：深空黑底 + 右下角几何网格线（10% 透明度技术靛蓝）。
- 页眉：品牌 Logo（深空黑或纯白，依底色）+ 文档标题，字号 9pt。
- 页脚：页码 + “Confidential” 声明（如适用）。

### 6.3 开发者大会 / PPT

- 背景：深空黑或深灰渐变。
- 图表：技术靛蓝为主数据色，荧光青为对比数据色，禁用红绿对比（色盲不友好）。
- 留白：每页文字不超过 6 行，行距 1.5 倍。

### 6.4 周边与印刷

- 笔记本/贴纸：深空黑底 + 荧光青 Logo，哑光覆膜。
- 工牌挂绳：技术靛蓝纯色，无 Logo 重复平铺。
- 禁止：在 T 恤上使用全幅渐变大图。
